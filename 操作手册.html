只需三步：登录后台 → 安装技能 → 说出姓名和月份。取数、分析、排版全部自动完成。 支持联席（某联席名下学生）、教务（某教务全部学生）、课程（某门课全部学生，可下钻到联席）三种视角。请使用自己的后台账号。

登录后台（取凭证）

仅首次 / token 过期时

让 WorkBuddy 代你登录「学生管理后台」，自动保存凭证，无需自己操作。

你对 WorkBuddy 说：
帮我登录学生管理后台 stadminv2.xqmsx.cn 取 token
它会打开登录页 → 你输入自己的账号密码 + 图形验证码 → 自动存好凭证（有效期约 24 小时）。
1

安装技能

仅首次

把下面这条命令发给 WorkBuddy，让它运行一次即可。

你对 WorkBuddy 说：
帮我运行这条安装命令：bash <(curl -sL https://raw.githubusercontent.com/feidou-lxy/co-teacher-report/main/install.sh)
看到 「✅ 技能已安装到 ~/.workbuddy/skills/co-teacher-report」 即成功。 装完后请新开一个对话再继续（新技能需在新会话生效）。
2

生成学情分析

每次出分析

在新对话里，说出姓名 + 角色 + 月份即可。

联席视角：
用 co-teacher-report 技能，生成 张巍（联席） 2026年9月 的学情分析
教务视角：
用 co-teacher-report 技能，生成 罗绂燕（教务） 2026年9月 的学情分析
课程视角：
用 co-teacher-report 技能，生成 高二数学211层六C肖（课程） 2026年9月 的学情分析
换人 / 换月 / 换课：只改名字和月份即可。教务视角会拉出该教务管辖的全部学生，学情分析可切换「按课程」/「按联席」两种维度查看；课程视角直接拉出该门课的全部学生，下方可下钻到具体联席；联席视角按课程 Tab 切换。
两个角色的关注点不一样，报告会按角色自动调权重：
• 联席（为学习效果负责）：每张卡顶部给「联席四维」——互动状态（积极 / 不积极 / 沉默不回复）、催交作业是否交、批改后是否订正、提问意愿；「最该盯」也按这四维排。出勤只作背景（折叠、不给红黄绿）。
• 教务（为续报负责）：出勤是核心关切，逐节明细完整展开并给红黄绿提醒。
叠加小黑板读图（可选）：
用 co-teacher-report 技能，生成 高二数学211层六C肖（课程）2026年9月 的学情分析，并分析桌面「邵清北课上小黑板」文件夹里的学生小黑板图片
小黑板为可选项：把该课所有学生的小黑板图片放进一个本地文件夹，让 WorkBuddy 逐张读图，判断每生作答情况（正确 / 有错 / 空白）、定位典型错误并标注关联知识点，作为判断优势 / 薄弱知识点的直接依据写进学生卡片的「③ 学习掌握与薄弱点」——结论先行：先给薄弱知识点与优势，再附小黑板佐证（不嵌图片，只给文字结论）。小黑板错误会与聊天高频话题交叉验证，两者都命中的知识点标 🖍 双证据。需配置一个视觉模型（或走人工回填模板）。
你会拿到两份文件：
• <姓名>_学情分析.html —— 彩色学情分析页（学生姓名后标注购课类型：直播 / 回放；含速览＋联席四维、出勤、薄弱点（含小黑板佐证）、跟进动作）
• <姓名>_学生待办清单.xlsx —— 总览（含互动状态 / 催交作业 / 批改订正 / 提问意愿）+ 待办 + 出勤明细，可直接下发
⚠️ 三点提醒
  • token 约 24 小时过期：第二天再出分析，先重说第 0 步。
  • 装完技能要新开对话：否则可能没加载到技能。
  • 各用各账号：凭证只自己用，不要互传。
