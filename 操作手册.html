登录后台（取凭证）

仅首次 / token 过期时

这一步只做一件事：在浏览器里登录一次后台，把登录凭证（token）交给 WorkBuddy。 它不会、也不需要知道你的账号密码 —— 密码永远由你自己在浏览器里输。 下面两种做法，任选一种即可；做法一没反应就直接用做法二。

做法一 · 让 WorkBuddy 打开浏览器，你自己登录 推荐：配一次，以后每次都是一句话
1先做一次环境检查（只做这一次）：打开 WorkBuddy 的 设置 → Agent → 浏览器控制，把开关打开；按提示安装 WorkBuddy 浏览器扩展（Chrome / Edge / QQ 浏览器任选），装完在浏览器里把扩展点开登录一次。
2然后对 WorkBuddy 说这句话：
你对 WorkBuddy 说：
帮我登录学生管理后台 stadminv2.xqmsx.cn 取 token
3浏览器会自动打开后台登录页 → 你自己输入账号密码 + 图形验证码 → 点登录。凭证自动存好（有效期约 24 小时），接着就能出报告了。
找不到那个开关、或扩展装不上？不用纠结 —— 直接用下面的做法二，效果完全一样。
做法二 · 你自己登录，把凭证复制给它 零配置，半分钟；做法一没反应就用这个
1打开 stadminv2.xqmsx.cn，用自己账号正常登录（账号密码 + 图形验证码）。
2在这个页面按 F12 打开开发者工具 → 点上方的 Console 标签 → 输入下面这行，按回车：
在 Console 里输入：
document.cookie
3会打印出一长串，找到里面 token= 那一段，整段复制（不用自己删多余字符），发到对话里：
你对 WorkBuddy 说：
这是我的 token：<把复制的一整串粘贴在这里>，帮我出 2026年9月 的学情分析
4它会自动存好凭证，接着取数出报告。
🔧 说了半天没弹出浏览器？按顺序看这 4 条
  1. 浏览器控制开关没打开：WorkBuddy「设置 → Agent → 浏览器控制」需要打开。
  2. 没装浏览器扩展，或扩展没登录：装好 WorkBuddy 浏览器扩展后，在浏览器里点开扩展登录一次。
  3. 浏览器不在前台：把浏览器切到前台看看，登录页可能已经开好了；若有「允许连接」的提示，点一下。
  4. 还是不行，直接用「做法二」 —— 它不依赖任何配置，一定能成。也不要让它反复去试接口，那只会更慢。
🔒 账号密码只属于你：如果 WorkBuddy 反过来问你要账号密码、或说要用「账号密码登录接口」，不要给。 直接回它：「请打开浏览器让我自己登录，或者我自己复制 token 给你」。
⏰ 凭证约 24 小时过期：第二天再出报告，重做本步即可（用做法二最快）。

① 🚨 总人数覆盖与失联预警
回答「谁没被触达」。把在册学生按 5 档分好，并给出每档的建议动作： 失联（没沟通、也没出勤）｜出勤但无沟通（人在上课，只是群里没记录）｜单向沟通（只有老师在说）｜低互动（学生家长几乎不发言）｜正常。
用法：点「人数」那一格，就在这一行下面展开该档的名单（「失联」默认已展开）。上方「覆盖概览与判定口径」默认收起，需要核对口径时点开。
② 🎓 主讲备课建议
回答「下节课讲什么」＋「下节课点谁」。
• 建议重点讲什么：一张优先级表 —— 覆盖学生越多越靠前，同覆盖时「小黑板上有实证错误」的优先（那是学生真的答错了，比「群里提过」硬）。每条给典型题型 / 卡点，点开能看原文出处，直接用来选题。
• 👀 下节课可重点关注的学生（新）：默认列 前 6 位，每行给「学生 / 关注理由 / 课上可以做的事 / 依据」。详见下方单独说明。
③ 📋 学生学情 & To-Do
回答「每个学生具体怎么办」。顶部「近 3 天待回应」入口条 ＋ 姓名搜索框 ＋ 分组 Tab ＋ 一排可点的统计卡 ＋ 逐学生卡片。
用法：点统计卡（学生数 / 响应迟缓群 / 未解疑问群 / 互动不足 / 催交未交 / 批改未改；教务视角是「有缺勤」）只看这一类学生，再点一次（或点「学生数」）恢复全部；可以和「搜索姓名」「筛选联席」叠加用。
每组卡片最下方还有一条 ⚠️ 未触达预警 入口条 —— 见下方说明。
两张特殊卡片怎么用👀 下节课重点关注的学生 ｜ ⚠️ 预警卡
👀 下节课可重点关注的学生（在 Tab② 备课建议表的下方）
主讲一节课能额外点的就几个人。这份名单只收「课上互动不足」的学生，分两档： 沉默不回复／近期沉默（窗口内本人几乎没发言）→ 主动点名，先抛一个他大概率答得上的问题，把人带进课堂节奏； 不积极（本人发言很少）→ 多给一次点名提问 / 小黑板任务。
「发言量正常（属正常参与）」的学生不进名单 —— 否则一半人上榜，等于没筛。
小黑板只作为「第 2 个理由 + 排前依据」：如果这名学生既互动不足、课堂上又没落实（多轮没交 / 没写完 / 有实证错误），他会排在最前面 —— 那正是最该被点的人。
🔒 卡片里明确写了：「互动不足」不等于学生不用功，只复述群里和课堂上的既有事实，不评价态度、不预测成绩。默认 6 人，其余按同一口径点开看。
⚠️ 预警卡 —— 在册、却在群里一条记录都没有的学生
常规学生卡只覆盖「群里有聊天记录」的学生。所以在册、但群里一条消息都没有的学生（失联 / 出勤但无沟通）原本在报告里完全看不到 —— 而他们恰恰最该被看见。报告专门为这批人做了一张左侧红边的预警卡，把两件事摊开写清：
• 沟通轴：群到底建了没有、有没有人在里面说话；
• 学习轴：出勤几次、小黑板交了几张 → 据此判断学生是不是在正常上课；
• 再给结论、可直接执行的动作（谁去打电话、谁在群里点名反馈）、以及数据来源（花名册 / 群列表 / 聊天 / 小黑板 各自有没有），方便你回后台和文件夹逐条核对。

🔒 一句很重要的话：只要学习侧有证据（有出勤，或有小黑板作答），结论只会写「企业微信沟通通道失效」（等于群没建好 / 拉错人 / 家长没进群），绝不会写「学生流失」。实测这些学生全都在正常上课。只有「既没沟通、也没有出勤和小黑板」才会写「需人工核实就读状态」。

怎么展开（新改的）：预警卡数量可能不少（教务视角可能上百张），所以它默认收起，放在每组学生卡片的下方，不占正常信息的版面。两种展开方式： ⚠️ 另有 N 名在册学生未进入学情分析（无聊天记录）　　点击展开预警卡 ▾ ① 点这条入口条 —— 就地展开 / 收起； ② 点这组上方统计卡里的「未触达预警」 —— 隐藏常规学生卡、只留预警卡。 再点一次「学生数」即可全部恢复。用姓名搜索时如果搜到的是预警卡学生，这一区会自动展开，不会搜不到。
📖 报告怎么看 · 详细说明（点击展开）
两个角色的关注点不一样，报告会按角色自动调权重：
• 联席（为学习效果负责）：每张卡右上角给一枚「学习分层」徽章（需重点关注 / 需关注 / 正常 / 良好），由课堂小黑板 + 作业闭环 + 老师反馈 + 学生成绩四方面证据综合判定，判定依据可在 ① 块末尾点击展开（依据里逐条给出加减分，标题给出累计总分，可以自己核对）；① 学习情况给成绩（群里发过月考 / 期中成绩时才有这一行）、具体薄弱点（从「知识点」下钻到题型 / 方法，如「直线和圆」→「含参直线过定点」，每条都附原文出处、可回群核对）与优势（小黑板佐证折叠）；② 配合度给「联席四维」（互动状态 / 催交作业是否交 / 批改后是否订正 / 提问意愿）＋群内发言人分布（谁在说话、各说了多少条，可回群核对）；③ 行动清单按优先级排序、第 1 条即「最该盯」。出勤只汇总成一句话。
• 教务（为续报负责）：出勤是核心关切，在该句话下另附逐节明细与红黄绿提醒。
卡片结构（v4.0 去重，重点更突出）：每张卡 = 右上角「学习分层」徽章 ＋ 3 块 —— ① 学习情况（只留具体薄弱点与优势；小黑板的逐次课 / 逐轮明细、以及分层判定依据均折叠）→ ② 配合度（行为事实：待回应提醒、配合度结论、四维、出勤一句话、信号条）→ ③ 行动清单（第 1 条即「最该盯」，全报告动作清单只此一处，不再与 ② 重复）。右上角不再同时出现两个分层标签。
📊 学生成绩算进「学习效果」：群里定期会发月考 / 期中成绩，这是判断学习效果最硬的依据，所以单独作为一类证据参与分层，并且能盖过平时的作业与配合表现 —— 成绩好（得分率 ≥85%）→ 就算平时作业不做，也属于「学习效果较好」，档位直接托底到「良好」； 成绩偏低（<65%）→ 就算作业都交、群里也很配合，也属于「学习效果不好」，档位封顶在「需关注」； 成绩中等则小幅加分。群里没发过成绩就不参与判分（不加不减），卡片上也不会多出这一行。
识别是保守的：必须同时看到「考试名（月考/期中/期末/联考…）」和「能归到这名学生头上的分数」才算数，只提「考试范围 / 考试时间」、或只写了卷面满分，都不会被当成成绩；把别人分数写成他的名字也不会算到他头上；实在认不出就按「无成绩」处理，不会拿一个裸数字硬凑。分数没写满分时按学科推断（数学按 150 分制）并会在依据里注明「按 150 分制推断」。
🧭 学习分层是怎么算出来的：四类证据各加减分、累加后落档：≤−3 需重点关注 ｜ −2~−1 需关注 ｜ 0~+1 正常 ｜ ≥+2 良好。改进的三点 ——
①「老师指出问题」不再数绝对次数，改成密度（每 10 轮小黑板里的指出次数）：因为数学群里老师天天纠错是常态，按绝对次数算会「人人扣分」；
② 小黑板把「没写完」和「不会」分开：「思路对了但没写完」属课堂节奏 / 书写速度，不再算到能力头上，只有真正的错误才扣分；
③ 加了成绩这一层托底 / 封顶（见上）。这样四档才重新分得开。
👆 统计卡可以点着筛人：每张卡上方那一排统计卡（学生数 / 响应迟缓群 / 未解疑问群 / 互动不足 / 催交未交 / 批改未改；教务视角是「有缺勤」）都是筛选按钮 —— 点一下只看这一类学生，再点一下（或点「学生数」）恢复全部，下方会显示「已筛选：XXX · N 人」，可以和「搜索学生姓名」「筛选联席」叠加用。页面最下面的「方法论与口径说明」默认收起，需要时点标题展开。
🎯 具体薄弱点（下钻到题型）：①「学习情况」不再只写「直线和圆」这种知识点大类，而是给出两级清单——知识点 → 具体题型 / 方法，例如「直线和圆」下面的「含参直线过定点」、「圆的一般式与圆心坐标」、「斜率是否存在（分类讨论）」。每条后面都带原文出处（老师原话 / 学生提问原文 / 小黑板卡点），可以回群里逐字核对；标签颜色区分来源：老师指出 / 学生提问 / 小黑板，重复出现的标 ×N。若某生确实找不到能下钻到题型的证据，会退回原来的知识点范围并说明原因（不会硬编一个题型出来）。
这份清单是「聊天记录 ＋ 小黑板每次课每一轮」一起归纳出来的 —— 所以同一个题型后面标 ×3，往往意味着「课上连续几轮都卡在这类题」。
🗂 课程名从哪来：报告里的课程名直接取后台的课程名（响应时效列表的「课程」列，完整格式带前缀，如 2026Q-SX-高二数学清北层日E邵），不再从群名去猜。原因是群名和后台课程名经常对不上：群名可能漏了班型（少「进化班」）、缺字（「清北层E邵」少了「日」）、甚至写成另一门课。所以 —— 要生成课程视角的报告时，课程名请从后台「课程」列整串复制，不要照抄群名。反过来也有好处：群名写错的群现在能被正确归到真实课程（实测补回了 1 个群名漏字的学生）。
另外：这个课程名需要「整串完全一致」，抄错一个字就会找不到课程（会明确提示你）。学生与群的匹配也因此更准 —— 最新版实测覆盖率接近 9 成，比早先的做法多找出十几个群。
📐 知识点归属：「求轨迹 / 轨迹方程」类题目归 「曲线与方程」，不归「圆锥曲线」 —— 教材里「曲线与方程」讲的是求轨迹方程，「圆锥曲线」讲的是椭圆 / 双曲线 / 抛物线的几何性质（离心率、韦达定理、定点定值这些）。所以看到「定义与轨迹判定」出现在「曲线与方程」下面，是正常的；发现某条题归错大类，告诉我就好（改的是识别维度表，归档的旧读图结果会自动改归，不用重读图）。
出勤口径：看回放也算有效出勤（有效出勤 = 到课 + 未到课但已看回放），只有「既没到课也没看回放」才算缺课。呈现为「出勤 4/5 次（含回放 2 次），缺课 1 次」这样一句话。
🚨 近 3 天待回应（重点标记）：报告会结合近 3 天的聊天记录，检查有没有「联席忘记回复」（学生提问后群里再无老师消息）或「学生问题未解决」（老师说了「稍后 / 晚点」却没下文，或学生 24 小时内再次追问）。一旦发现，会在报告顶部给出「🚨 近 3 天待回应 N 项」入口条（默认收起，点击展开全量明细表：学生 / 日期 / 类型 / 提问原文 / 依据 / 建议动作 —— 这是给管理者 / 教务的统一视图），并在对应学生卡头部打红徽标、② 配合度内置置顶清单，同时生成最高优先级跟进动作（即 ③ 行动清单第 1 条）；没有任何问题则显示绿色「检查通过」。
👪 配合度怎么看：报告不会因为「家长发言少」就写家长不配合 —— 学生在群里越积极，家长往往越不发言，不是不配合，而是没必要出面。现在的做法：① 家长侧只在学生自驱不足时才判负面；② 家长出面量用硬事实 —— 卡片里直接列出群内发言人分布（如「墨墨说 162 条 ｜ 张震环 4 条」），谁在说话、说了多少条一目了然，可回群逐条核对；③ 两个防误判闸门 —— 家长零发言时不硬扣「配合偏弱」；次发言者昵称与学生昵称含共同汉字时判为「疑似学生本人另一账号」，不按家长计。
判定精度（重要）：「学生问题未解决」只在两种情况成立 —— ① 老师说了「稍后 / 晚点 / 回头」这类应允却没下文（且不是在说排课 / 假期安排）；② 老师回复后 24 小时内，学生明确表示仍然困惑（还是不会 / 没懂 / 不明白 / 没解决）再次追问。师生之间正常的多轮深挖不再误报。另外，若用合成 / 演示数据试跑，报告顶部会有一条橙色横幅注明数据来源 —— 看到它就知道报告里的提问原文在真实群里搜不到属正常。
🧩 报告里的学生数，为什么比在册人数少？这是正常的。报告主体（学生卡片）只覆盖「群里有聊天记录」的学生；剩下的人没有聊天记录，做不出常规学生卡，但他们没有消失 —— 都在 Tab① 的分档名单 里，并且以 Tab③ 的预警卡形式单独呈现。所以看到「学生数」和在册人数对不上，先去看 Tab①。
你会拿到一份文件：
• <姓名｜课程名>_学情分析.html —— 彩色学情分析页，三大 Tab：① 失联预警（点人数展开名单）② 主讲备课建议（讲什么 ＋ 👀 点谁）③ 学生学情 & To-Do（筛选卡 ＋ 逐生卡片 ＋ ⚠️ 预警卡）。学生姓名后标注购课类型（直播 / 回放），右上角学习分层徽章。
• 不再产出 Excel：全部结论（含待办清单）都在这一个 HTML 报告里，直接转发即可。
常见问题出错先看这里
Q：说「帮我取 token」，但浏览器没弹出来 / 一直转圈？
说明它没拿到浏览器控制权。先按第 0 步的「🔧 4 条排查」看一眼（开关、扩展、前台）； 懒得查就直接用第 0 步的「做法二」：你自己登录后台 → F12 → Console 输入 document.cookie → 把 token= 那一串整段粘给它，半分钟就一定成。 不要为了这一步去装浏览器组件、更不要在对话里反复试接口。
Q：它问我要后台账号密码，能给吗？
不要给。取凭证只需要「浏览器里登录后的那一串 token」，全程不需要你的密码。 直接回它：「请打开浏览器让我自己登录，或者我自己复制 token 给你」。
Q：第二天再出报告，提示登录失败 / 取不到数据？
凭证（token）大约 24 小时过期，重做第 0 步再出报告即可 —— 最快是「做法二」（自己登录 → 复制 token 粘过来）。
Q：说完了却没反应 / 提示没有这个技能？
技能安装后需要新开一个对话才会生效。先新开对话，再说第 2 步那句话。
Q：报告里搜不到某个学生？
两种情况：① 他在 Tab① 的分档名单里（没有聊天记录，所以没有常规学生卡）；② 他是预警卡学生 —— 用姓名搜索时会自动展开预警区，或者直接点那组上方的「未触达预警」统计卡。
Q：课程视角提示「找不到该课程」？
课程名要整串完全一致（连 2026Q-SX- 这类前缀一起），请从后台「响应时效」列表的「课程」列复制，不要手打、也不要照抄群名（群名经常漏字或写错层级）。
Q：小黑板图片要放在哪？命名有要求吗？
放进一个本地文件夹（比如桌面「邵清北课上小黑板」），然后在那句话里点名这个文件夹即可。目录结构按「一次课 / 那一轮」两层放好（脚本会按目录去重计数），图片文件名里能认出学生姓名就能对上号。命名/目录整理好一次，以后每个月都能复用。
Q：第二个月出报告，小黑板要重新读一遍吗？
不用。读过的图会被自动复用，只读新加进来的那几张；图片被替换过则会自动重读。
Q：报告里的数字能拿去跟家长说吗？
可以，但建议先点开依据核对：卡片里每条结论都带原文出处（老师原话 / 学生提问 / 小黑板卡点），报告里的「具体薄弱点」「待回应」都能回群、回图逐字找到对应记录。报告只复述已发生的事实，不评价态度、不预测成绩。
Q：技能有更新怎么办？
把第 1 步那条安装命令再运行一次就更新到最新版了，然后新开对话。历史报告不受影响。
⚠️ 四点提醒
  • token 约 24 小时过期：第二天再出分析，先重做第 0 步（做法二最快）。
  • 装完技能要新开对话：否则可能没加载到技能。
  • 各用各账号：凭证只自己用，不要互传。
  • 不用给密码：任何时候都不需要把后台账号密码告诉 WorkBuddy。
