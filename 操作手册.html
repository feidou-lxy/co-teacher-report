生成学情分析

每次出分析

在新对话里，说出姓名 + 角色 + 月份即可。

联席视角：
用 co-teacher-report 技能，生成 张巍（联席） 2026年9月 的学情分析
教务视角：
用 co-teacher-report 技能，生成 罗绂燕（教务） 2026年9月 的学情分析
课程视角：
用 co-teacher-report 技能，生成 高二数学211层六C肖（课程） 2026年9月 的学情分析
换人 / 换月 / 换课：只改名字和月份即可。教务视角会拉出该教务管辖的全部学生，学情分析可切换「按课程」/「按联席」两种维度查看；课程视角直接拉出该门课的全部学生，下方可下钻到具体联席；联席视角按课程 Tab 切换。
两个角色的关注点不一样，报告会按角色自动调权重：
• 联席（为学习效果负责）：每张卡右上角给一枚「学习分层」徽章（需重点关注 / 需关注 / 正常 / 良好），由课堂小黑板 + 作业闭环 + 老师反馈 + 学生成绩四方面证据综合判定，判定依据可在 ① 块末尾点击展开（v4.4：依据里逐条给出加减分，标题给出累计总分，可以自己核对）；① 学习情况给成绩（群里发过月考 / 期中成绩时才有这一行）、具体薄弱点（v4.2：从「知识点」下钻到题型 / 方法，如「直线和圆」→「含参直线过定点」，每条都附原文出处、可回群核对）与优势（小黑板佐证折叠）；② 配合度给「联席四维」（互动状态 / 催交作业是否交 / 批改后是否订正 / 提问意愿）；③ 行动清单按优先级排序、第 1 条即「最该盯」。出勤只汇总成一句话。
• 教务（为续报负责）：出勤是核心关切，在该句话下另附逐节明细与红黄绿提醒。
卡片结构（v4.0 去重，重点更突出）：每张卡 = 右上角「学习分层」徽章 ＋ 3 块 —— ① 学习情况（只留具体薄弱点与优势；小黑板的逐次课 / 逐轮明细、以及分层判定依据均折叠）→ ② 配合度（行为事实：待回应提醒、配合度结论、四维、出勤一句话、信号条）→ ③ 行动清单（第 1 条即「最该盯」，全报告动作清单只此一处，不再与 ② 重复）。右上角不再同时出现两个分层标签。
📊 学生成绩算进「学习效果」（v4.4 新增）：群里定期会发月考 / 期中成绩，这是判断学习效果最硬的依据，所以单独作为一类证据参与分层，并且能盖过平时的作业与配合表现 —— 成绩好（得分率 ≥85%）→ 就算平时作业不做，也属于「学习效果较好」，档位直接托底到「良好」； 成绩偏低（<65%）→ 就算作业都交、群里也很配合，也属于「学习效果不好」，档位封顶在「需关注」； 成绩中等则小幅加分。群里没发过成绩就不参与判分（不加不减），卡片上也不会多出这一行。
识别是保守的：必须同时看到「考试名（月考/期中/期末/联考…）」和「能归到这名学生头上的分数」才算数，只提「考试范围 / 考试时间」、或只写了卷面满分，都不会被当成成绩；把别人分数写成他的名字也不会算到他头上；实在认不出就按「无成绩」处理，不会拿一个裸数字硬凑。分数没写满分时按学科推断（数学按 150 分制）并会在依据里注明「按 150 分制推断」。
🧭 分层是怎么算出来的（v4.4 重校）：四类证据各加减分、累加后落档：≤−3 需重点关注 ｜ −2~−1 需关注 ｜ 0~+1 正常 ｜ ≥+2 良好。改进的三点 ——
①「老师指出问题」不再数绝对次数，改成密度（每 10 轮小黑板里的指出次数）：因为数学群里老师天天纠错是常态，按绝对次数算会「人人扣分」；
② 小黑板把「没写完」和「不会」分开：「思路对了但没写完」属课堂节奏 / 书写速度，不再算到能力头上，只有真正的错误才扣分；
③ 加了成绩这一层托底 / 封顶（见上）。这样四档才重新分得开 —— 之前所有学生都挤在「需重点关注」，徽章等于没用。
👆 统计卡可以点着筛人（v4.3）：每张卡上方那一排统计卡（学生数 / 响应迟缓群 / 未解疑问群 / 互动不足 / 催交未交 / 批改未改；教务视角是「有缺勤」）都是筛选按钮 —— 点一下只看这一类学生，再点一下（或点「学生数」）恢复全部，下方会显示「已筛选：XXX · N 人」，可以和「搜索学生姓名」「筛选联席」叠加用。（原来那块没用的「可分析消息」统计已去掉；页面最下面的「方法论与口径说明」也改成默认收起，需要时点标题展开。）
🎯 具体薄弱点（v4.2 新增，下钻到题型）：①「学习情况」不再只写「直线和圆」这种知识点大类，而是给出两级清单——知识点 → 具体题型 / 方法，例如「直线和圆」下面的「含参直线过定点」、「圆的一般式与圆心坐标」、「斜率是否存在（分类讨论）」。每条后面都带原文出处（老师原话 / 学生提问原文 / 小黑板卡点），可以回群里逐字核对；标签颜色区分来源：老师指出 / 学生提问 / 小黑板，重复出现的标 ×N。若某生确实找不到能下钻到题型的证据，会退回原来的知识点范围并说明原因（不会硬编一个题型出来）。
这份清单是「聊天记录 ＋ 小黑板每次课每一轮」一起归纳出来的（v4.3：小黑板改成全量读图，一次课一轮都不落）——所以同一个题型后面标 ×3，往往意味着「课上连续几轮都卡在这类题」。
出勤口径：看回放也算有效出勤（有效出勤 = 到课 + 未到课但已看回放），只有「既没到课也没看回放」才算缺课。呈现为「出勤 4/5 次（含回放 2 次），缺课 1 次」这样一句话。
🚨 近 3 天待回应（v3.9 新增，重点标记）：报告会结合近 3 天的聊天记录，检查有没有「联席忘记回复」（学生提问后群里再无老师消息）或「学生问题未解决」（老师说了「稍后 / 晚点」却没下文，或学生 24 小时内再次追问）。一旦发现，会在报告顶部给出「🚨 近 3 天待回应 N 项」入口条（默认收起，点击展开全量明细表：学生 / 日期 / 类型 / 提问原文 / 依据 / 建议动作 —— 这是给管理者 / 教务的统一视图），并在对应学生卡头部打红徽标、② 配合度内置置顶清单，同时生成最高优先级跟进动作（即 ③ 行动清单第 1 条）；没有任何问题则显示绿色「检查通过」。
判定精度（v4.1 收紧 · 重要）：「学生问题未解决」只在两种情况成立 —— ① 老师说了「稍后 / 晚点 / 回头」这类应允却没下文（且不是在说排课/假期安排）；② 老师回复后 24 小时内，学生明确表示仍然困惑（还是不会 / 没懂 / 不明白 / 没解决）再次追问。师生之间正常的多轮深挖不再误报（旧口径曾在真实数据上把一名积极学生连判 7 项）。另外，若用合成/演示数据试跑，报告顶部会有一条橙色横幅注明数据来源 —— 看到它就知道报告里的提问原文在真实群里搜不到属正常。

你会拿到一份文件：
• <姓名>_学情分析.html —— 彩色学情分析页（学生姓名后标注购课类型：直播 / 回放；右上角学习分层徽章；① 学习情况：具体薄弱点（下钻到题型、附原文出处）＋优势＋折叠的小黑板佐证 ② 配合度：待回应提醒＋四维＋出勤一句话 ③ 行动清单：按优先级排序、首条即「最该盯」）
• v3.9 起不再产出 Excel：全部结论（含待办清单）都在这一个 HTML 报告里，直接转发即可
