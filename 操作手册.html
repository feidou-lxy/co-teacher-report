生成学情分析

每次出分析

在新对话里，先想清楚用哪个视角（看谁的学生），再说一句话：技能 ＋ 谁 ＋ 哪段时间（如 9月1日-9月30日）。下面把三种视角并列成三个页签，点一下切换查看；每种都标明了你要准备什么、操作几步、会得到什么 —— 照抄「你说」那一行即可。想连课堂小黑板一起分析，就看橙色「别忘了加小黑板」一行，照着说就不会漏。

🖍 小黑板读图（可选 · 三种视角都能加）：上面每张角色卡都给了「加了小黑板的完整句子」，照着说就行，别漏这一句 —— 漏了报告里就只有聊天记录、没有课堂作答那部分。 用法：把该课所有学生的小黑板图片放进一个本地文件夹（如桌面「邵清北课上小黑板」），在说话时点名这个文件夹，WorkBuddy 就会逐张读图 —— 一次课、一轮都不能漏（报告里的「具体薄弱点」是聊天 ＋ 每次课每一轮一起归纳出来的，只读一轮会把结论做偏）。读图判断每生作答情况（完整 / 部分 / 空白未提交）、定位典型错误与卡点并标注关联知识点，作为判断优势 / 薄弱点的直接依据写进学生卡片的「薄弱知识点」那一行，以及卡头的一句话诊断里。 ⚡ 同一张图只读一次：第二次、第三次出报告时，读过的图会被自动复用，只读新加进来的那几张，所以第二次起会明显更快；图片被替换过则会自动重读。同一批学生的小黑板数据可以跨月、跨课程反复用。
换人 / 换时间段 / 换课：只改名字和时间段即可。教务视角会拉出该教务管辖的全部学生，学情分析可切换「按课程」/「按联席」两种维度查看；课程视角直接拉出该门课的全部学生，下方可下钻到具体联席；联席视角按课程 Tab 切换。
♻️ 同一份报告再看一次，几秒就好（v4.49 新增）
第一次出某人的报告要几分钟（要拉群聊、算出勤、读小黑板）；之后再看同一个人，只需要几秒 —— 上次的数据原样复用，只重新拉「续报 / 在读科目 / 扩科意向」这几项会变的东西。
怎么说：直接说「把罗绂燕的学情分析刷新一下」或「更新一下续报数据」，不用再给日期；只要上次登录还没满一天，也不用重新认验证码。
这几种情况不能用「刷新」，要正常重新生成：① 换了新的时间段（比如想看 10 月）；② 距上次出报告已经超过一天多（凭证过期，会提示你重新登录）；③ 想看到新发生的群聊（刷新只更新教务那几项，不重读聊天）。
⚠️ 刷新后数字没变，不代表刷新失败：如果后台还没人维护「是否续报」，那批学生永远是「续报未确认」，刷多少次都一样（见下方 FAQ）。
报告存在哪：同一个人 / 同一门课的报告现在都放在同一个固定位置，不会每生成一次就新建一个文件夹。找不到就问一句「我的报告存在哪」。
报告打开后先看哪：三大 Tab顶部 KPI 卡全部可点击，点了会自动跳到对应位置
报告现在分三个 Tab，对应三个不同的问题：谁没被触达？下节课讲什么、点谁？每个学生具体怎么办？ 顶部那排数字卡（总人数 / 失联 / 出勤但无沟通 / 响应迟缓 / 待回复 / 近 3 天待回应）都是按钮，点一下就筛出对应的人。
① 🚨 总人数覆盖与失联预警
回答「谁没被触达」。把在册学生按 5 档分好，并给出每档的建议动作： 失联（没沟通、也没出勤）｜出勤但无沟通（人在上课，只是群里没记录）｜单向沟通（只有老师在说）｜低互动（学生家长几乎不发言）｜正常。
用法：点「人数」那一格，就在这一行下面展开该档的名单（「失联」默认已展开）。上方「覆盖概览与判定口径」默认收起，需要核对口径时点开。

学生卡头部的身份行（v4.39 · v4.42）
教务报告的学生卡，学校下面会多一行：在读科目（标签）＋ 续报（已续报 / 未续报）＋ 扩科意向（科目 chip ＋ 后面直接跟原文依据）。
🔒 这一行「有内容才显示」：没续报记录就不显示续报、没扩科意向就不显示扩科、在读科目为空就整组不显示 —— 所以你看到某个学生卡片上少几项是正常的，不是数据丢了，而是「这项他没有」。
⚠️「续报未确认」是什么？为什么有的人全是这个？
这个数字 = 后台还没有人维护过他的续报状态。来源是后台「是否续报」字段（是 / 否 / 未设置）， 「未设置」就是学生尚未选择、或教务还没在后台填 —— 它是真实业务状态，不是系统没取到数据。
判断依据：「是」→ 已续报（绿）；「否」→ 未续报（红）；「未设置」或后台没有这个学生 → 续报未确认（橙）。橙色卡片上悬停能看到具体是「学生未选」还是「后台没返回」。
所以「已续报 0 / 未续报 0 / 续报未确认 144」是可能的 —— 意思是这批人后台一个都还没标。等教务在后台把续报填上，这些数字会自动变成绿的或红的。
🔍 扩科意向是怎么识别的（不会瞎猜）：扫该学生本人在群里的发言，同时满足两条才记：① 提到别的科目（英语 / 物理 / 化学 / 语文…）② 附近 25 字内有扩科意图词（报名 / 想报 / 想学 / 咨询 / 加课 / 打算 / 补 / 试听…）。
另外排除了 4 类噪声：招生活动发言、营销话术（含 🔥 / 热报名中）、「英语老师 / 英语作业」这类语境、以及「加课 / 报课」离科目太远（在说别的科目）的情况。
🔒 卡片和明细里都直接给出那段原文（前后各 25 字），可以回群逐字核对 —— 识别不到就不显示，不会硬凑一个意向出来。
两张特殊卡片怎么用👀 下节课重点关注的学生 ｜ ⚠️ 预警卡（点击展开）
⚠️ 建议先跟进的学生（在 Tab② 学生情况概览表的下方）
主讲一节课能额外点的就几个人。这份名单只收「课上互动不足」的学生，分两档： 沉默不回复／近期沉默（窗口内本人几乎没发言／已经 14 天没说过学习相关的话）→ 主动点名，先抛一个他大概率答得上的问题，把人带进课堂节奏； 只闲聊不学习／不积极（有发言但无一条涉及学习；或学习相关发言 ≤2 条）→ 多给一次点名提问 / 小黑板任务。
⭐ v4.50：判据改看「学习相关发言」，不看发言总量 —— 群里聊得欢但不聊学习的，照样进名单。
「学习相关发言正常（属正常参与）」的学生不进名单 —— 否则一半人上榜，等于没筛。
小黑板只作为「第 2 个理由 + 排前依据」：如果这名学生既互动不足、课堂上又没落实（多轮没交 / 没写完 / 有实证错误），他会排在最前面 —— 那正是最该被点的人。
🔒 卡片里明确写了：「互动不足」不等于学生不用功，只复述群里和课堂上的既有事实，不评价态度、不预测成绩。默认 6 人，其余按同一口径点开看。
⚠️ 预警卡 —— 在册、却在群里一条记录都没有的学生
常规学生卡只覆盖「群里有聊天记录」的学生。所以在册、但群里一条消息都没有的学生（失联 / 出勤但无沟通）原本在报告里完全看不到 —— 而他们恰恰最该被看见。报告专门为这批人做了一张左侧红边的预警卡，把两件事摊开写清：
• 沟通轴：群到底建了没有、有没有人在里面说话；
• 学习轴：出勤几次、小黑板交了几张 → 据此判断学生是不是在正常上课；
• 再给结论、可直接执行的动作（谁去打电话、谁在群里点名反馈）、以及数据来源（花名册 / 群列表 / 聊天 / 小黑板 各自有没有），方便你回后台和文件夹逐条核对。

🔒 一句很重要的话：只要学习侧有证据（有出勤 —— 含看回放，或有小黑板作答），结论只会写「企业微信沟通通道失效」（等于群没建好 / 拉错人 / 家长没进群），绝不会写「学生流失」。实测这些学生全都在正常上课（含「没到直播、自己看回放补课」的）。只有「既没沟通、也没有出勤和小黑板」才会写「需人工核实就读状态」。

怎么展开（新改的）：预警卡数量可能不少（教务视角可能上百张），所以它默认收起，放在每组学生卡片的下方，不占正常信息的版面。两种展开方式： ⚠️ 另有 N 名在册学生未进入学情分析（无聊天记录）　　点击展开预警卡 ▾ ① 点这条入口条 —— 就地展开 / 收起； ② 点这组上方统计卡里的「未触达预警」 —— 隐藏常规学生卡、只留预警卡。 再点一次「学生数」即可全部恢复。用姓名搜索时如果搜到的是预警卡学生，这一区会自动展开，不会搜不到。
📖 报告怎么看 · 详细说明（点击展开）
两个角色的关注点不一样，报告会按角色自动调权重：
• 联席（为学习效果负责）：每张卡右上角一枚「学习分层」徽章（需重点关注 / 需关注 / 正常 / 良好），由五类证据综合判定 —— ① 课堂小黑板作答 ② 作业闭环 ③ 老师反馈 ④ 学生成绩 ⑤ 飞书表的提交与评级（v4.23 起把飞书表纳入，不再是单独一块，而是拆成片段参与判断；v4.50 起飞书表的「总结」列也计入完成情况 —— 学生课后自写的复盘，取值 已交 / 未交 / #N/A；其中被评为 「佳作」 的单独记，不混进完成率，悬停「作业提交」那一格能看到「其中佳作 N 次」）。卡片一眼就能看完：诊断句（一句话说清这个学生现状）→ 四格指标 → 学生问题 → 薄弱知识点 → 最该做 / 其次；再往下两个折叠。出勤只作背景。
• 教务（为续报负责）：出勤是核心关切，在该句话下另附逐节明细；卡片头部另有在读科目 / 续报 / 扩科意向身份行，Tab② 顶部有教务核心数据统计块。
卡片结构（v4.34 「一眼 + 两折」）：不再按「①学习情况 / ②配合度 / ③To-Do」三块并列 —— 那样要跨三块自己拼结论，信息太长。现在一眼看完结论，明细收进折叠：
【卡头】姓名（后面跟购课类型直播 / 回放）→ 近期成绩（群里发过月考 / 期中才显示）→ 学校 → 课程名（＋联席）→ 教务视角多一行身份行（在读科目 / 续报 / 扩科意向）→ 右上角学习分层徽章。
【一眼】① 诊断句：一句话把现状说完（例「群里 12 天没说话，本人一共发过 2 条；不过主动提问 9 处」）。🔒 只做事实组合，不加形容词、不下判断 —— 不会出现「这孩子可能在掉队」这种话。
② 四格指标：作业提交（飞书表完成 ÷（完成＋未完成），含「总结」列）｜出勤（有效出勤，含回放）｜学习发言（与学习／提问相关的发言条数，v4.50 改口径）｜最近学习（最后一次学习相关发言距今几天）。颜色只表示这一格好不好，点住能看到口径说明。
⭐ v4.50「学习发言」怎么算：只看跟学习有关的发言（题目、答案、思路、没听懂、卡住、直播回放、讲义笔记、作业提交、订正、考试、知识点…）。群里刷屏聊闲天不算 —— 以前按发言总量算，话多的学生会被顶成「积极」，闷头做题的反而不积极，现在这个偏差已经修掉。实测：本人实质发言里只有约 29% 与学习相关。
⭐ 因此「互动状态」新增一档 「只闲聊不学习」：有发言、但一条都没涉及学习 —— 这类学生不会被判成积极。
③ 学生问题（v4.37）：把飞书表里「学生学情 / 问题点」的原句切出来显示 —— 红 = 行为 / 态度类，橙 = 基础 / 状态类。🔒 原句照搬、不改写、不加工。
④ 薄弱知识点（v4.35）：显示知识点名 ＋ 出现条数（最多 4 枚）；点某一枚才展开该知识点下的具体题型 / 方法和原文出处 —— 不用点两次才能看到重点。
⑤ 最该做 / 其次：橙色「最该做」那条加粗；「其次」固定显示、不折叠；第 3 条起才折进下面的「其余跟进建议」。
【两折】「补充信息」（作业明细 / 跟进痕迹 / 老师手记 / 群内提及 / 响应 / 情绪 / 家长参与 / 飞书表出处）＋「其余跟进建议」（第 3 条起，含跟进节奏）。
【已隐藏】「学习分层判定依据」整行不再显示（太长、且是内部计算过程）。想核对某个学生为什么被判成这一档，直接问 WorkBuddy「某某为什么是需重点关注」，它会把这名学生的加减分明细列给你。
📊 学生成绩算进「学习效果」：群里定期会发月考 / 期中成绩，这是判断学习效果最硬的依据，所以单独作为一类证据参与分层，并且能盖过平时的作业与配合表现 —— 成绩好（得分率 ≥85%）→ 就算平时作业不做，也属于「学习效果较好」，档位直接托底到「良好」； 成绩偏低（<65%）→ 就算作业都交、群里也很配合，也属于「学习效果不好」，档位封顶在「需关注」； 成绩中等则小幅加分。群里没发过成绩就不参与判分（不加不减），卡片上也不会多出这一行。
识别是保守的：必须同时看到「考试名（月考/期中/期末/联考…）」和「能归到这名学生头上的分数」才算数，只提「考试范围 / 考试时间」、或只写了卷面满分，都不会被当成成绩；把别人分数写成他的名字也不会算到他头上；实在认不出就按「无成绩」处理，不会拿一个裸数字硬凑。分数没写满分时按学科推断（数学按 150 分制）并会在依据里注明「按 150 分制推断」。
🧭 学习分层是怎么算出来的：五类证据各加减分、累加后落档：≤−3 需重点关注 ｜ −2~−1 需关注 ｜ 0~+1 正常 ｜ ≥+2 良好。前四类是 ① 小黑板 ② 作业闭环 ③ 老师反馈 ④ 成绩，v4.23 起加入第 ⑤ 类：飞书表的提交情况与作业评级（提交率、评级 A/B/C 的趋势）。改进的三点 ——
①「老师指出问题」不再数绝对次数，改成密度（每 10 轮小黑板里的指出次数）：因为数学群里老师天天纠错是常态，按绝对次数算会「人人扣分」；
② 小黑板把「没写完」和「不会」分开：「思路对了但没写完」属课堂节奏 / 书写速度，不再算到能力头上，只有真正的错误才扣分；
③ 加了成绩这一层托底 / 封顶（见上）。这样四档才重新分得开。
👆 统计卡可以点着筛人：每张卡上方那一排统计卡（学生数 / 响应迟缓群 / 未解疑问群 / 互动不足 / 催交未交 / 批改未改；教务视角是「有缺勤」）都是筛选按钮 —— 点一下只看这一类学生，再点一下（或点「学生数」）恢复全部，下方会显示「已筛选：XXX · N 人」，可以和「搜索学生姓名」「筛选联席」叠加用。页面最下面的「方法论与口径说明」默认收起，需要时点标题展开。
🎯 具体薄弱点（下钻到题型）：①「学习情况」不再只写「直线和圆」这种知识点大类，而是给出两级清单——知识点 → 具体题型 / 方法，例如「直线和圆」下面的「含参直线过定点」、「圆的一般式与圆心坐标」、「斜率是否存在（分类讨论）」。每条后面都带原文出处（老师原话 / 学生提问原文 / 小黑板卡点），可以回群里逐字核对；标签颜色区分来源：老师指出 / 学生提问 / 小黑板，重复出现的标 ×N。若某生确实找不到能下钻到题型的证据，会退回原来的知识点范围并说明原因（不会硬编一个题型出来）。
这份清单是「聊天记录 ＋ 小黑板每次课每一轮」一起归纳出来的 —— 所以同一个题型后面标 ×3，往往意味着「课上连续几轮都卡在这类题」。
🗂 课程名从哪来：报告里的课程名直接取后台的课程名（响应时效列表的「课程」列，完整格式带前缀，如 2026Q-SX-高二数学清北层日E邵），不再从群名去猜。原因是群名和后台课程名经常对不上：群名可能漏了班型（少「进化班」）、缺字（「清北层E邵」少了「日」）、甚至写成另一门课。所以 —— 要生成课程视角的报告时，课程名请从后台「课程」列整串复制，不要照抄群名。反过来也有好处：群名写错的群现在能被正确归到真实课程（实测补回了 1 个群名漏字的学生）。
另外：这个课程名需要「整串完全一致」，抄错一个字就会找不到课程（会明确提示你）。学生与群的匹配也因此更准 —— 最新版实测覆盖率接近 9 成，比早先的做法多找出十几个群。
📐 知识点归属：「求轨迹 / 轨迹方程」类题目归 「曲线与方程」，不归「圆锥曲线」 —— 教材里「曲线与方程」讲的是求轨迹方程，「圆锥曲线」讲的是椭圆 / 双曲线 / 抛物线的几何性质（离心率、韦达定理、定点定值这些）。所以看到「定义与轨迹判定」出现在「曲线与方程」下面，是正常的；发现某条题归错大类，告诉我就好（改的是识别维度表，归档的旧读图结果会自动改归，不用重读图）。
出勤口径：看回放也算有效出勤（有效出勤 = 到课 + 未到课但已看回放），只有「既没到课也没看回放」才算缺课。呈现为「出勤 4/5 次（含回放 2 次），缺课 1 次」这样一句话。
v4.38 补充三点（都是实际踩过的坑）：
① 购「直播」课的学生，看直播和看回放都算出勤。所以四格里的出勤格一律写有效出勤，不会只写「到课 2/5」——否则一个到课 2 节 + 回放 2 节的学生会被读成「5 节只来了 2 节」，和同一张卡上的「出勤 4/5」自相矛盾。
② 全看回放、一节没到直播：只要看全了，就算完成，不上屏、不扣分（购回放课更是如此，看回放就是正常完成）。
③ 只缺 1 节时直接给节次：写「第 5 节没看」，比「5 节里 1 节没看」更短、还能直接定位到是哪节课。
这个口径也用于①失联预警的分档 —— 只要有效出勤不为 0，就不会被判成「失联」；出勤文案会写明「其中 N 次为看回放补齐」。若某位学生「一次直播都没到、全靠回放」，预警卡会写「未到直播、但已用回放把课补齐」，并提示你顺带问一句没来直播的原因。
🚨 近 3 天待回应（重点标记）：报告会结合近 3 天的聊天记录，检查有没有「联席忘记回复」（学生提问后群里再无老师消息）或「学生问题未解决」（老师说了「稍后 / 晚点」却没下文，或学生 24 小时内再次追问）。一旦发现，会在报告顶部给出「🚨 近 3 天待回应 N 项」入口条（默认收起，点击展开全量明细表：学生 / 日期 / 类型 / 提问原文 / 依据 / 建议动作 —— 这是给管理者 / 教务的统一视图），并在对应学生卡头部打红徽标、卡片内单独列一条置顶清单，同时生成最高优先级跟进动作（即卡内「最该做」那条）；没有任何问题则显示绿色「检查通过」。
👪 配合度怎么看：报告不会因为「家长发言少」就写家长不配合 —— 学生在群里越积极，家长往往越不发言，不是不配合，而是没必要出面。现在的做法：① 家长侧只在学生自驱不足时才判负面；② 家长出面量用硬事实 —— 卡片里直接列出群内发言人分布（如「小明说 162 条 ｜ 家长 4 条」），谁在说话、说了多少条一目了然，可回群逐条核对；③ 两个防误判闸门 —— 家长零发言时不硬扣「配合偏弱」；次发言者昵称与学生昵称含共同汉字时判为「疑似学生本人另一账号」，不按家长计。
判定精度（重要）：「学生问题未解决」只在两种情况成立 —— ① 老师说了「稍后 / 晚点 / 回头」这类应允却没下文（且不是在说排课 / 假期安排）；② 老师回复后 24 小时内，学生明确表示仍然困惑（还是不会 / 没懂 / 不明白 / 没解决）再次追问。师生之间正常的多轮深挖不再误报。另外，若用合成 / 演示数据试跑，报告顶部会有一条橙色横幅注明数据来源 —— 看到它就知道报告里的提问原文在真实群里搜不到属正常。
🧩 报告里的学生数，为什么比在册人数少？这是正常的。报告主体（学生卡片）只覆盖「群里有聊天记录」的学生；剩下的人没有聊天记录，做不出常规学生卡，但他们没有消失 —— 都在 Tab① 的分档名单 里，并且以 Tab③ 的预警卡形式单独呈现。所以看到「学生数」和在册人数对不上，先去看 Tab①。
你会拿到一份文件：
• <姓名｜课程名>_学情分析.html —— 彩色学情分析页，三大 Tab：① 失联预警（点人数展开名单）② 学生情况概览（普遍卡在哪 ＋ 谁最该先跟进；教务视角另含教务核心数据）③ 学生学情 & To-Do（筛选卡 ＋ 逐生卡片 ＋ ⚠️ 预警卡）。学生姓名后标注购课类型（直播 / 回放），右上角学习分层徽章。
• 不再产出 Excel：全部结论（含待办清单）都在这一个 HTML 报告里，直接转发即可。
• 存在哪（v4.49）：同一个人 / 同一门课的报告固定放在 ~/.workbuddy/reports/ 下的同名文件夹里（如 edu-罗绂燕、co-张巍、course-高二数学清北层日E邵）。下次刷新/重出会覆盖同一份，不会越攒越乱；要找旧报告就问一句「我的报告都存在哪」。
常见问题出错先看这里
Q：验证码看不清 / 它说打不开浏览器？
验证码看不清：回一句「看不清，换一张」即可，它会刷新验证码重新截图给你。
打不开浏览器：先让它再试一次；仍不行就回「用兜底方式取 token」—— 它会给你「自己登录 → F12 → Console → document.cookie → 把 token= 整串粘过来」这条路，半分钟一定成。 不要为了这一步去装浏览器组件、更不要在对话里反复试「登录接口」。
Q：真要把后台账号密码发给它吗？
要，这是最省事的方式。它用账号密码把登录页打开并填好， 图形验证码由你看图回复 —— 你全程不用开浏览器、不用按 F12。 账号密码只用于这次登录：不会写进报告，也不会存进技能文件。
⚠️ 两点注意：请用自己的后台工作账号，不要互传账号密码；若实在不想发，就走上面「🔧 万一卡住了」里的兜底方式。
Q：第二天再出报告，提示登录失败 / 取不到数据？
凭证（token）大约 24 小时过期，把第 0 步那句话再说一遍重新登录，再出报告即可。
Q：说完了却没反应 / 提示没有这个技能？
技能安装后需要新开一个对话才会生效。先新开对话，再说第 2 步那句话。
Q：只想出半个月（或某段时间）的报告，行吗？
行。在第 2 步那句话里把时间写成起止日期即可，如「2026年9月15日-9月30日」；报告里的响应时效、待回应、薄弱点等统计都按这个区间算。只写「9月」就按整月（9月1日-9月30日）出。三种视角写法完全一样，只改名字和时间段。
Q：报告里搜不到某个学生？
两种情况：① 他在 Tab① 的分档名单里（没有聊天记录，所以没有常规学生卡）；② 他是预警卡学生 —— 用姓名搜索时会自动展开预警区，或者直接点那组上方的「未触达预警」统计卡。
Q：课程视角提示「找不到该课程」？
课程名要整串完全一致（连 2026Q-SX- 这类前缀一起），请从后台「响应时效」列表的「课程」列复制，不要手打、也不要照抄群名（群名经常漏字或写错层级）。
Q：小黑板图片要放在哪？命名有要求吗？
放进一个本地文件夹（比如桌面「邵清北课上小黑板」），然后在那句话里点名这个文件夹即可。目录结构按「一次课 / 那一轮」两层放好（脚本会按目录去重计数），图片文件名里能认出学生姓名就能对上号。命名/目录整理好一次，以后每个月都能复用。
Q：第二个月出报告，小黑板要重新读一遍吗？
不用。读过的图会被自动复用，只读新加进来的那几张；图片被替换过则会自动重读。
Q：报告里的数字能拿去跟家长说吗？
可以，但建议先点开依据核对：卡片里每条结论都带原文出处（老师原话 / 学生提问 / 小黑板卡点），报告里的「具体薄弱点」「待回应」都能回群、回图逐字找到对应记录。报告只复述已发生的事实，不评价态度、不预测成绩。
Q：教务报告里「续报」几乎全是「未确认」，是不是没取到数据？
不是，这是真实业务状态。续报状态来自后台「是否续报」字段（是 / 否 / 未设置）， 「未设置」= 学生还没选、或教务还没在后台填，报告只能如实标成「续报未确认」。 等后台把这些标上，报告里的数字会自动变成「已续报」（绿）或「未续报」（红）。
反过来，如果「已续报 / 未续报」显示的是「—」而不是数字，那才是接口没返回（整批都没有数据）， 这种情况告诉 WorkBuddy 即可。
Q：教务报告的「课程」标签在哪切？为什么 Tab② 里找不到课程下拉了？
课程筛选已经上移到页面顶部，是一条贯穿全报告的「课程」标签条 —— 点某个课程， 顶部数字卡、Tab② 的教务核心数据、Tab③ 的学生卡会一起跟着变，再点「全部课程」取消。 这样设计是因为课程是整体筛选维度，不该在某个 Tab 里单独切（否则两个 Tab 显示的口径会打架）。
Q：只想让「续报 / 在读科目」这些数字变新，还要重新等几分钟吗？
不用。说完「把 XX 的学情分析刷新一下」后，它只重新拉一次教务那几项数据、再重排一遍页面，几秒就好，不会重新拉群聊。
但要注意：刷新只更新续报 / 在读科目 / 扩科意向，新发生的群聊内容不会进报告 —— 想连聊天一起更新，还是要说那句话重新生成一份（第一次几分钟）。
另外，如果后台还没人维护「是否续报」，刷新后看到还是「续报未确认」是正常的，不是刷新失败。
Q：技能有更新怎么办？
把第 1 步那条安装命令再运行一次就更新到最新版了，然后新开对话。历史报告不会丢 —— 报告存在单独的 ~/.workbuddy/reports/ 目录里，更新技能不会碰它（v4.49 起）。
Q：孩子群里天天说话，为什么还写「只闲聊不学习」／「不积极」？
因为 v4.50 起，「积极」只看跟学习有关的发言，不看说了多少句。
算学习相关的：问题目、说没听懂 / 卡住 / 不会做、说思路和步骤、聊直播回放 / 讲义 / 笔记、交作业 / 订正、考试和成绩、具体知识点（函数、导数、数列…）， 以及上课设备问题（网络登不上、classin 进不去）也算 —— 那确实影响学习。
不算的：「在吗」「吃了吗」「晚安」「哈哈」「红包」「多少钱」，以及退费、优惠、报名、接送、价格这类事务性内容。
所以：如果一位学生发了 40 条但全是「老师好」「哈哈哈」，报告会判他只闲聊不学习，这是刻意的 —— 以前按发言总量算，话多的被顶成积极、闷头做题的反而不积极，那个偏差已经修掉了。
要复核很容易：把鼠标放在「学习发言」这一格上，会显示「本人实质发言共 N 条」，两个数一起看就知道差在哪。
⚠️ 四点提醒
  • token 约 24 小时过期：第二天再出分析，把第 0 步那句话再说一遍重新登录即可。
  • 装完技能要新开对话：否则可能没加载到技能。
  • 各用各账号：凭证只自己用，不要互传账号密码。
  • 验证码由你回：它会截图发你，你回 4 位数字；看不清就回「换一张」，不要自己猜。
