# 联席学情报告技能 · co-teacher-report

把企业微信班级群聊天 + 后台课节考勤（＋可选的小黑板手写作答图片读图），一键生成「联席 / 教务 / 课程」三视角学情报告（HTML）。

## 一键安装（推荐）

```bash
bash <(curl -sL https://raw.githubusercontent.com/feidou-lxy/co-teacher-report/main/install.sh)
```

脚本会把技能装到 `~/.workbuddy/skills/co-teacher-report/`。
（如需指定其他仓库/分支：`REPO=https://github.com/其他账号/co-teacher-report BRANCH=main bash <(curl -sL <install.sh地址>)`）

## 手动安装

```bash
git clone https://github.com/feidou-lxy/co-teacher-report.git /tmp/co-teacher-report
mkdir -p ~/.workbuddy/skills
rm -rf ~/.workbuddy/skills/co-teacher-report
mv /tmp/co-teacher-report ~/.workbuddy/skills/co-teacher-report
```

## 使用（用你自己的后台账号）

1. 登录 `stadminv2.xqmsx.cn`，从任意请求头取出 `x-token`（JWT，约 24 小时有效）
2. 写入工作目录：
   ```bash
   mkdir -p ~/co-report && echo "粘贴你的x-token" > ~/co-report/token.txt
   ```
3. 生成报告（仅用 Python 标准库，无需第三方依赖）：
   ```bash
   # 联席视角
   python ~/.workbuddy/skills/co-teacher-report/scripts/run_all.py \
     --co <联席名> --window 2026-09-01 --month 2026-09
   # 教务视角
   python ~/.workbuddy/skills/co-teacher-report/scripts/run_all.py \
     --edu <教务名> --window 2026-09-01 --month 2026-09
   # 课程视角（一门课跨多个联席）；可选带上小黑板图片目录一起分析
   # ⚠️ v4.7：课程名从后台「响应时效」列表的「课程」列复制（如 高二数学985层进化班六D谢胡），
   #          不要照抄群名 —— 群名可能漏班型/缺字/写成别的课程
   python ~/.workbuddy/skills/co-teacher-report/scripts/run_all.py \
     --course 高二数学211层六C肖 --window 2026-09-01 --boards ~/Desktop/小黑板目录
   ```
4. 产物：`<联席|教务|课程名>_学情分析.html`（v3.9 起不再产出 Excel，全部结论都在报告内）

## 版本与口径（v4.9）

- **「高频知识点」表改为双源**：此前这张表**只统计聊天文本命中**（`extract.top_topics`），
  小黑板的实证错误**完全没进这张表** —— 而小黑板才是学生真实作答、最能说明「哪里不会」的证据。
  现并列展示两列：**群聊提及**（聊天中命中该知识点的学生数）与 **小黑板实证**（读图判定该知识点
  **有错误／卡点**的学生数），末列「合计涉及」为两源并集。
- **新增「🎓 主讲备课建议 · 下节课重点讲什么」**（紧随高频知识点表，三视角均渲染）：
  - 一句话结论 + 优先级表 + **可折叠的题型证据**（每条附原文出处，可回群 / 回图核对）。
  - 排序：**覆盖学生数降序**（普遍性优先）；同覆盖时**有小黑板实证错误的优先**
    —— 小黑板是学生真实作答，比「群里提过」硬。
  - 直接给出**具体题型**（如「含参直线过定点」「基底法与共面向量」），供主讲备课选题。
- ⚠️ **题型证据分硬／软**（与 v4.4 学习分层口径一致）：
  - 标 **`实证错误 N`** = 读图判「有错」或存在**非「没写完」**类实质错误 → **真的不会**；
  - 标 **`仅未完成／卡点`** = 只是没写完（课堂节奏 / 书写速度）→ **不是能力问题**，不混为一谈。
- 🐞 **修复 `NO_FINISH_ERR` 漏匹配（包含式判定）**：读图模型对同一件事有「未完成收尾」与
  **「收尾未完成」**两种词序，**后者才是真实语料主流写法**（实测 176 条错误标注中占 94 条），
  而旧词表写的是前者 → **精确匹配静默失效**。现统一走 `common.is_finish_err()` 包含式判定，
  「未完成 / 未收尾 / 未写完」各种写法都能识别。
- 🔒 **反编造**：题型名只能来自 `FINE_TYPES` 词表命中或字段原文（形如「课堂作答卡点：…」），
  无证据时如实说明、留空，**绝不硬凑题型名**；不预测考情、不生成内容。

## 版本与口径（v4.8）

- **新增「在册全覆盖与失联预警」（报告顶部独立区块）**。旧版学生卡只覆盖**有聊天记录**的学生，
  而在册名单往往明显更大 —— **差额恰恰是最需要预警给老师的一批人，旧版把他们静默漏掉了**。
  现按「出勤 × 聊天」两轴把余下的人收口成四档：
  | 档 | 判定 | 动作 |
  |---|---|---|
  | **失联** | 无聊天记录 **且** 无出勤记录 | 最高优先级，逐一核实是否退课 / 从未建群 |
  | **出勤但无沟通** | 无聊天记录 **且** 有出勤记录 | 学生在正常上课，缺的是企业微信沟通通道 → 补建 / 核对群并主动触达 |
  | **单向沟通** | 有聊天记录，但学生·家长实质发言 = 0 | 换沟通方式，制造回应点 |
  | **低互动** | 有聊天记录，实质发言 1~2 条 | 关注并适度引导 |
- ⚠️ **红线：判「失联」一律以出勤为准，不以群是否存在为准。** 群列表接口 `wxworkSessionStat/getList`
  只收录有响应时效记录的群，**天然有损** —— 实测「教务罗绂燕」视角 **243 人在册、群仅 144**
  （缺口分散在全部 7 门课，其中 **93 人仍在正常出勤**）。若拿群判失联，会**一次性误报约四成学生**。
  故群「采到与否」只作根因标签（`group_missing` / `group_empty`）展示。
- **两轴窗口必须分开**：沟通轴取**近 14 天**（`--chat-days`，全月窗口会掩盖「近期才沉默」）；
  学习轴取**报告窗口全窗口**（出勤本稀疏，只看近 14 天会把已结课学生全判「无出勤」→ 误报失联）。
  学习证据 = **出勤 或 小黑板**（存在「无出勤记录但有小黑板作答」的学生，只看出勤会误判）。
- **新增「中间契约」分层（`references/data_contract.md`）**：`pull_*` 是取数层，
  `adapt_legacy.py`（今天）/ `adapt_api.py`（研发统一接口到位后）是**可替换的适配器**，
  `snapshot/*.json` 是**稳定的中间契约**，`coverage.py` / `extract.py` / `report.py` 是**不动的分析层**。
  **接口变了只改适配器**。缺失字段一律写入 `snapshot/meta.json` 的 `degraded[]` 并在报告里明示，**绝不静默兜底**。
- **新增两步**：`adapt_legacy.py`（折算快照）→ `coverage.py`（覆盖率 + 四档分档 → `coverage.json`），
  排在 `merge.py` 与 `report.py` 之间；`run_all.py` 已自动编排。
  `coverage.py` 内置**守恒断言**：`#在册 == #coverage` 且五档人数之和 == 在册人数（每人有且只有一档）。
- **报告头图两个分母写清**：预警按近 14 天、学生卡按报告窗口，两者不等时报告里会说明差额
  （= 窗口内互动过、但近 14 天已沉默的人，同样计入「无沟通」）。

## 版本与口径（v4.5）

- **配合度：家长侧归因修正（v4.5）**。修正一个**伪结论** —— **学生本人在群里很活跃时，家长往往就隐身了**，
  这不是「家长配合一般」，而是「家长没必要出面」；旧口径把「家长发言少」直接映射为负面定级，属**归因错位**。
  - **家长出面量改用硬事实**：群内「除主导发言人外的其他发言人条数」（`n_other`）。聊天数据带发言人昵称
    （`name`，role=2 侧），报告卡片直接列出「群内发言人 XXX N 条 ｜ YYY M 条」，**可回群逐条核对**；
    不再用「学生本人话语也会命中的家长措辞词表」估分。
  - **学生自驱达标（≥中等）时，家长少出面只做中性描述、不下负面结论** —— 旧口径的
    「家长配合一般 / 家长配合偏弱 / 家长参与较少」三个负面档位在整份报告里已不再出现。
  - **两个防反向伪结论的闸门**：**(a)** 家长零发言痕迹 → 改判「建议先联系家长确认」，不硬扣「配合偏弱」；
    **(b)** 次发言者昵称与学生主昵称**含共同汉字**（如「毛毛～💕」vs「毛星空～💕」）→ 判为
    **「疑似学生本人另一账号」**，不按家长计。正面强结论（「家长在群内配合」）需家长措辞或昵称不可疑佐证。
  - 典型输出：「学生自驱标杆级（窗口内本人主动提问 68 处）；家长较少在群内出面（另有 4 条发言 ·
    学生自主推进中，家长无需代劳）。」
  - **实测（144 人真实教务存档）**：旧口径 64 人「家长参与较少」/ 38 人「家长配合一般」/ 30 人「家长配合偏弱」，
    新口径下**三个负面档位全部清零**。

## 版本与口径（v4.4）

- **学习分层口径重校 + 新增「学生成绩」为第四类证据（最强证据）**。背景：旧口径下真实数据**所有学生都被判「需重点关注」**，四档退化成一档、徽章失去区分度。改了四处：
  - **③ 老师反馈 → 密度归一化**：旧口径按「指出问题**绝对次数**」扣分（≥3 处即 −2），但真实数学群里老师高强度纠错是**教学常态**（实测三位学生分别在 2/8/8 次课里被指出 11/12/9 处），人人触发、人人扣分。现按「**每 10 轮小黑板**（无小黑板数据时按每 100 条可分析消息）」的指出密度：≥10 → −2、≥5 → −1、未超基线不扣；正面评价 ≥3 → +1~+2。
  - **① 小黑板把「没写完」和「不会」分开**：真实读图里 `未完成收尾` 占错误标注 **25/33** —— 大量轮次是「思路对了但没写完」，属**课堂节奏 / 书写速度**，不再按能力扣分（仅占比 ≥85% 时轻提示 −1）。只有剔除它之后的**实质错误**（计算错误 / 判断错误 / 思路偏差 / 推导跳步 / 漏解…）才按占比扣分（≥30% → −2、≥20% → −1）；「完整作答且无错」≥60% / ≥40% 给 +2 / +1；空白未提交归参与度。
  - **④ 学生成绩（新增 · 最强证据）**：`common.extract_exam()` 从群聊里定期收集的**月考 / 期中成绩**中识别（**只匹配、不生成**）。业务口径：**成绩好（得分率 ≥85%）→ 即使平时作业不做，也属「学习效果较好」→ 档位托底「良好」**；**成绩偏低（<65%）→ 即使作业都交、很配合，也属「学习效果不好」→ 档位封顶「需关注」**；成绩中等 → +1；无成绩 → 0。
    - 保守识别：必须命中考试名关键词（月考/期中/期末/联考/测验…）**且**能归因到本人（句内出现姓名，或分数前不是别人的名字），并排除「满分/总分/卷面」后的数字与「考试范围/时间/报名」事务句；认不出即「未知」，**绝不用裸数字硬凑**。无满分标注时按学科推断（数学 150、其余 100）并注明「按 X 分制推断」。自带 14 条回归用例（含 5 条「应跳过」负例）。
    - 真实数据验证：在 144 人教务存档里**命中 2 例真实成绩**且均逐字核对属实（「老师我们考完月考了 成绩106/120」；「月考141」被老师回复「那9分扣在哪」反证满分 150）。
  - **依据块可核对**：折叠的「学习分层判定依据」现在**逐条给出加减分**，标题给出**累计总分**（成绩托底/封顶时另标「成绩托底 / 成绩封顶」）。
- **实测分布（144 名真实学生，教务视角）**：需重点关注 **8** / 需关注 **73** / 正常 **58** / 良好 **5**（累计分 −4 ~ +4）—— 四档重新有区分度。
- **成绩行**：有成绩时卡片 ① 顶部多一行「成绩：月考 128/150（得分率 85%）· 10-08 ＋ 出处原文」；无成绩时整行不出现。

## 版本与口径（v4.3）

- **报告顶部统计卡可点击筛选**：分组统计区每一张 KPI 小卡都是筛选入口 —— `学生数 / 响应迟缓群 / 未解疑问群 / 互动不足 / 催交未交 / 批改未改`（教务视角末位为 `有缺勤(后台)`）。**点一下只保留这一类学生，再次点击（或点「学生数」）恢复全部**，下方提示「已筛选：X · N 人」，可与「搜索学生姓名」「筛选联席」叠加使用。
- **「可分析消息」统计下线**：该数字对跟进动作没有指导意义，且每张卡片 meta 行已有「可分析 N 条」，属同源重复。
- **「四、方法论与口径说明」默认隐藏**：只留一行标题，点击才展开全文，避免长文压版面。
- **小黑板改成「每次课 × 每一轮」全量读图**（关键修复）：之前只读了 1 次课 1 轮（3 张），而实际有 **8 次课 29 轮（63 张）**。① 学习情况里的「具体薄弱点」必须是**聊天记录 ＋ 小黑板每轮结果一起归纳**的产物 —— 只读一轮会把结论做偏。
  - 实践做法：按「学生 × 课次」分批（如 7 批 / 63 张），并行读图产出 `result_N.json`，再合并成 `board_analysis.json`；每批自检「条数 = 输入条数、`path` 一一对应」。
- **小黑板侧细粒度口径收紧**：① 跳过 `空白未提交`（没作答 = 出勤/参与度问题，不是知识点薄弱）；② 跳过 `topic` 为「其他」的**问卷 / 调查表**；③ 跳过「完整作答 + 正确 + 无错」。另引入 `BOARD_KW_BLOCK`（`定点 / 投影 / 斜率 / 对称 / 轨迹`）—— 这些词在聊天口语里有效，但在**题干**里遍地都是，只在小黑板侧屏蔽。
- **维度表按真实题干扩充**：`立体几何/空间向量` 增 `向量线性相关／点集判定`、`动点与多结论判断`、`平行与垂直的证明`；`直线和圆` 增 `存在性与构造`、`轨迹与阿波罗尼斯圆`、`两圆／两定点最值`、`平行线间距离`，并把 `弦长公式` 扩为 `弦长／截线问题`。关键词全部取自真实题干 / 语料原话。
- **知识点归属修正（v4.6，用户口径）**：新增大类 **`曲线与方程`**，把 **`定义与轨迹判定`** 从 `圆锥曲线` 移过去 —— **求轨迹类题目属「曲线与方程」，不属「圆锥曲线」**（教材「圆锥曲线与方程」一章里，「曲线与方程」讲求轨迹方程，「圆锥曲线」讲三种曲线的几何性质）。同时引入 `common.ITEM_TOPIC`（题型 → 强制归属）：① 该表内的题型在题型名打分中**直接拿最高优先级**（否则同句里的泛化题型会把它抢走 —— 真实数据里「距离之和」同时命中 `两圆／两定点最值`、「定点」命中 `定点定值问题`，导致这条被误归类且读图的 topic 加权反而帮了倒忙）；② 聚合时按题型**自动纠正读图给出的 topic**，归档的旧读图结果无需重读图。

## 版本与口径（v4.2）

- **去重收口（v4.2）**：有细粒度证据时**只呈现细粒度**，聊天侧「错误类型」不再单独出现（与其同源、粒度更粗 —— 这正是 v4.0 用户反馈的「三部分内容重复」）；确实下钻不到题型时，才退回粗知识点 chips ＋ 一句「聊天高频错因」兜底。

### v3.8 及更早口径

- **学习情况分层（v3.8 新增 · v4.4 重校）**：综合**四类证据**判档 —— **① 课堂小黑板作答**（课次·轮次·空白/实质错误/仅未完成占比·趋势）+ **② 作业闭环**（催交是否交、批改后是否订正）+ **③ 老师反馈**（指出问题**密度** / 正面评价）+ **④ 学生成绩**（月考 / 期中，**最强证据**，可托底 / 封顶档位）。档位：**需重点关注 / 需关注 / 正常 / 良好**。作业闭环做对、小黑板完整作答且无错都会加分，避免人人被判重点关注。详见上方「版本与口径（v4.4）」。
- **配合度（v4.5 归因修正）**：结论 =「学生自驱」＋「家长是否出面」，且**家长侧只在学生自驱不足时才判负面**。
  家长出面量用**硬事实**（群内非主导发言人的实际条数），卡片里直接列出「群内发言人 XXX N 条 ｜ YYY M 条」便于回群核对；
  学生自驱达标时家长少出面只做中性描述；家长零痕迹或次发言者疑似学生第二账号时不下家长定级。详见上方「版本与口径（v4.5）」。
- **出勤口径修正（v3.8，重要）**：**看回放也算有效出勤**（有效出勤 = 到课 + 未到课但已看回放），只有「既没到课也没看回放」才算真缺课 —— 修正前会把已看回放的节次误判成缺课。呈现统一为**一句话**（如「出勤 4/5 次（含回放 2 次），缺课 1 次，第 5 节既没到课也没看回放」）；**联席不再单独占模块**，教务在该句话下附折叠的逐节明细。

- **三视角**：`--co <联席名>` 联席视角（**联席维度 · 按课程下钻**）；`--edu <教务名>` 教务视角（双维度：按课程 / 按联席下钻）；`--course <课程名>` **课程视角**（**课程维度 · 按联席下钻**，适合「分析某门课下所有学生」）。三种视角共用同一套分析逻辑。
- **职责分工（v3.7 关键口径）**：**联席为学习效果负责** → 看**「联席四维」**＋薄弱知识点/优势，**出勤只作背景**（折叠、不给红黄绿、不参与定档）；**教务为续报负责** → **出勤是核心关切**（完整展开＋红黄绿，异常计入教务定档）＋家长沟通。
  - 「课程-联席」与「联席-课程」两个维度是当前重点：前者＝课程视角按联席下钻（学生卡标所属联席），后者＝联席视角按课程 Tab 切换。

  1. **互动状态**：积极 / 一般 / 不积极 / **沉默不回复**
  2. **催交作业 → 是否交**：老师催交后 72h 内学生是否提交（`已提交/催交次数`）
  3. **批改后 → 是否订正**：老师要求订正后 72h 内学生是否改正（`已改正/订正次数`）
  4. **提问意愿**：高 / 中 / 低 / 无
  - **联席 To-Do 严格按四维排序**（互动 → 答疑闭环 → 催交 → 订正 → 提问意愿）；**出勤/请假不再进入联席 To-Do**，避免「确认出勤/补回放」抢走联席的「最该盯」。
