学生学情报告 · 操作手册

3 步出报告（联席 / 教务双视角），全程只用跟 WorkBuddy 说话，不用写代码

🗣️ 对话驱动 🔑 自动登录取凭证 📊 出 HTML + Excel
你只需要做三件事：让 WorkBuddy 登录后台 → 让它装技能 → 告诉它查谁、查哪个月。 所有取数、分析、排版都由技能自动完成。请使用你自己的后台账号，不要和他人共用。
可查联席（某联席名下学生，按课程切换）或教务（某教务管辖的全部学生，按下属联席下钻）。
0

准备后台凭证（让 WorkBuddy 帮你登录）

仅首次 / token 过期时

报告数据来自「学生管理后台」，需要你的登录凭证（x-token）。不用你自己找，让 WorkBuddy 代你登录并自动保存。

你对 WorkBuddy 说：
帮我登录学生管理后台 stadminv2.xqmsx.cn 取 token
WorkBuddy 会打开登录页面 → 你输入自己的账号密码 + 图形验证码 → 它自动把 token 存好（有效期约 24 小时）。 这一步只需在第一次用、或第二天再跑时重复做一次。
1

安装技能（只做一次）

仅首次

把下面这条命令发给 WorkBuddy，让它帮你运行一次，技能就装好了。

你对 WorkBuddy 说：
帮我运行这条安装命令：bash <(curl -sL https://raw.githubusercontent.com/feidou-lxy/co-teacher-report/main/install.sh)
看到 「✅ 技能已安装到 ~/.workbuddy/skills/co-teacher-report」 就成功了。 装完之后，请重新开一个对话再走下一步（刚装的技能需要在新会话里才会生效）。
2

生成报告（查谁、查哪个月）

每次出报告

在新对话里，把姓名、角色（联席 / 教务）和月份告诉 WorkBuddy 即可。

你对 WorkBuddy 说（联席视角）：
用 co-teacher-report 技能，生成 张巍（联席） 2026年9月 的学情报告
你对 WorkBuddy 说（教务视角）：
用 co-teacher-report 技能，生成 罗绂燕（教务） 2026年9月 的学情报告
换人 / 换月：只改名字和月份，其它不变。例如查「李娜（联席）2026年10月」就照说。 教务视角会一次性拉出该教务管辖的全部学生（跨多个下属联席），报告顶部可切换两种查看维度： ① 按课程维度（课程 Tab 切换，每个课程下还能「筛选联席」，课程 → 联席两级下钻）； ② 按联席维度（按下属联席分组下钻，横向对比各联席学情）。
报告最后一块会随角色自动变化：联席视角是「联席跟进 Action」（跟课、答疑、批改、作业订正）；教务视角是「教务 To-Do」（家长沟通、反馈学生问题、建立信任、推动续报）。 技能自动拉群聊 + 出勤，几分钟后给你两份文件。
你会拿到：
• <姓名>_学情分析报告.html —— 彩色报告（联席按课程切换 / 教务双维度：按课程+按联席；速览 / 出勤 / 薄弱点 / 跟进动作——联席=联席跟进 Action，教务=教务 To-Do）
• <姓名>_学生待办清单.xlsx —— 总览 + 待办 + 出勤明细（含所属联席列），可直接下发（教务为「教务To-Do·按课程 / 按联席」两个 sheet）
⚠️ 三点提醒
  • token 约 24 小时过期：第二天再出报告，先重说第 0 步「帮我登录后台取 token」。
  • 装完技能要新开对话：否则 WorkBuddy 可能没加载到刚装的技能。
  • 各用各账号：凭证只自己用，不要发给别人，也不互传 token。
