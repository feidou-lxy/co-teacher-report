登录后台（取凭证）

仅首次 / token 过期时

让 WorkBuddy 代你登录「学生管理后台」，自动保存凭证，无需自己操作。

你对 WorkBuddy 说：
帮我登录学生管理后台 stadminv2.xqmsx.cn 取 token
它会打开登录页 → 你输入自己的账号密码 + 图形验证码 → 自动存好凭证（有效期约 24 小时）。

安装技能

仅首次

把下面这条命令发给 WorkBuddy，让它运行一次即可。

你对 WorkBuddy 说：
帮我运行这条安装命令：bash <(curl -sL https://raw.githubusercontent.com/feidou-lxy/co-teacher-report/main/install.sh)
看到 「✅ 技能已安装到 ~/.workbuddy/skills/co-teacher-report」 即成功。 装完后请新开一个对话再继续（新技能需在新会话生效）。

生成学情分析

每次出分析

在新对话里，说出姓名 + 角色 + 月份即可。

联席视角：
用 co-teacher-report 技能，生成 张巍（联席） 2026年9月 的学情分析
教务视角：
用 co-teacher-report 技能，生成 罗绂燕（教务） 2026年9月 的学情分析
课程视角：
用 co-teacher-report 技能，生成 高二数学211层六C肖（课程） 2026年9月 的学情分析
换人 / 换月 / 换课：只改名字和月份即可。教务视角会拉出该教务管辖的全部学生，学情分析可切换「按课程」/「按联席」两种维度查看；课程视角直接拉出该门课的全部学生，下方可下钻到具体联席；联席视角按课程 Tab 切换。
两个角色的关注点不一样，报告会按角色自动调权重：
• 联席（为学习效果负责）：每张卡右上角给一枚「学习分层」徽章（需重点关注 / 需关注 / 正常 / 良好），由课堂小黑板 + 作业闭环 + 老师反馈三方面证据综合判定，判定依据可在 ① 块末尾点击展开；① 学习情况给薄弱知识点与优势（小黑板佐证折叠）；② 配合度给「联席四维」（互动状态 / 催交作业是否交 / 批改后是否订正 / 提问意愿）；③ 行动清单按优先级排序、第 1 条即「最该盯」。出勤只汇总成一句话。
• 教务（为续报负责）：出勤是核心关切，在该句话下另附逐节明细与红黄绿提醒。
卡片结构（v4.0 去重，重点更突出）：每张卡 = 右上角「学习分层」徽章 ＋ 3 块 —— ① 学习情况（只留薄弱知识点与优势；聊天侧「错误类型」已并入薄弱点行尾注，不再单列；小黑板的逐次课 / 逐轮明细、以及分层判定依据均折叠）→ ② 配合度（行为事实：待回应提醒、配合度结论、四维、出勤一句话、信号条）→ ③ 行动清单（第 1 条即「最该盯」，全报告动作清单只此一处，不再与 ② 重复）。右上角不再同时出现两个分层标签。
出勤口径：看回放也算有效出勤（有效出勤 = 到课 + 未到课但已看回放），只有「既没到课也没看回放」才算缺课。呈现为「出勤 4/5 次（含回放 2 次），缺课 1 次」这样一句话。
🚨 近 3 天待回应（v3.9 新增，重点标记）：报告会结合近 3 天的聊天记录，检查有没有「联席忘记回复」（学生提问后群里再无老师消息）或「学生问题未解决」（老师说了「稍后 / 晚点」却没下文，或学生 24 小时内再次追问）。一旦发现，会在报告顶部给出「🚨 近 3 天待回应 N 项」入口条（默认收起，点击展开全量明细表：学生 / 日期 / 类型 / 提问原文 / 依据 / 建议动作 —— 这是给管理者 / 教务的统一视图），并在对应学生卡头部打红徽标、② 配合度内置置顶清单，同时生成最高优先级跟进动作（即 ③ 行动清单第 1 条）；没有任何问题则显示绿色「检查通过」。
判定精度（v4.1 收紧 · 重要）：「学生问题未解决」只在两种情况成立 —— ① 老师说了「稍后 / 晚点 / 回头」这类应允却没下文（且不是在说排课/假期安排）；② 老师回复后 24 小时内，学生明确表示仍然困惑（还是不会 / 没懂 / 不明白 / 没解决）再次追问。师生之间正常的多轮深挖不再误报（旧口径曾在真实数据上把一名积极学生连判 7 项）。另外，若用合成/演示数据试跑，报告顶部会有一条橙色横幅注明数据来源 —— 看到它就知道报告里的提问原文在真实群里搜不到属正常。

用 co-teacher-report 技能，生成 高二数学211层六C肖（课程）2026年9月 的学情分析，并分析桌面「邵清北课上小黑板」文件夹里的学生小黑板图片
小黑板为可选项：把该课所有学生的小黑板图片放进一个本地文件夹，让 WorkBuddy 逐张读图，判断每生作答情况（正确 / 有错 / 空白）、定位典型错误并标注关联知识点，作为判断优势 / 薄弱知识点的直接依据写进学生卡片的「① 学习情况」——结论先行：先给薄弱知识点与优势；小黑板佐证只给「一句话作答概况 ＋ 典型错误」，每次课的情况 / 逐轮明细默认折叠，需要时点击展开（不嵌图片，只给文字结论）。小黑板错误会与聊天高频话题交叉验证，两者都命中的知识点标 🖍 双证据。需配置一个视觉模型（或走人工回填模板）。
你会拿到两份文件：
• <姓名>_学情分析.html —— 彩色学情分析页（学生姓名后标注购课类型：直播 / 回放；右上角学习分层徽章；① 学习情况：薄弱点＋优势＋折叠的小黑板佐证 ② 配合度：待回应提醒＋四维＋出勤一句话 ③ 行动清单：按优先级排序、首条即「最该盯」）
• v3.9 起不再产出 Excel：全部结论（含待办清单）都在这一个 HTML 报告里，直接转发即可
⚠️ 三点提醒
  • token 约 24 小时过期：第二天再出分析，先重说第 0 步。
  • 装完技能要新开对话：否则可能没加载到技能。
  • 各用各账号：凭证只自己用，不要互传。
